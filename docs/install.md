# Instalación · Flux

## Windows

Descarga el ZIP de una release, extrae todo su contenido y abre flux.exe. Mantén las DLL y la carpeta data junto al ejecutable. Si la release incluye instalador, sigue su asistente.

## Android

Descarga el APK publicado y ábrelo en el dispositivo. Autoriza la instalación desde esa fuente solo si Android lo solicita. Las actualizaciones deben conservar la misma firma.

## Conecta la red

Para descubrimiento local, conecta el emisor y el reproductor a la misma red. Las redes de invitados y el aislamiento entre clientes pueden impedir que se vean.

## Televisores

La aplicación receptora debe estar instalada cuando la función la requiera. Acepta el emparejamiento en la TV. Abrir Flux en TV no instala aplicaciones ni enciende el televisor.

## Identidad y actualizaciones

El identificador Android oficial es com.auralix.flux. Puedes buscar actualizaciones desde Red y opciones → Acerca de Flux. En Android se comprueba la integridad del archivo descargado antes de abrir el instalador. Android exige el mismo identificador y la misma firma, además de un número de compilación mayor, para conservar la instalación y sus datos.

## Actualizar Windows

El aviso de actualización abre el ZIP de la publicación correspondiente. Comprueba su SHA-256, cierra Flux y extrae el bundle completo. El reemplazo de archivos es manual; conserva las DLL y la carpeta data junto a flux.exe.

## Si usabas una edición anterior

Una edición con otro identificador Android se instala como una aplicación distinta. Conserva tus archivos y exporta lo que permita esa edición antes de migrar; los datos privados no se transfieren automáticamente. No desinstales la aplicación anterior hasta comprobar la nueva.
