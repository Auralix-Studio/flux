# Privacidad · Flux

## Descubrimiento local

El descubrimiento contacta dispositivos y puertos de la red para encontrar emisiones. Los destinos conocidos y las preferencias pueden guardarse localmente para usos posteriores.

## Navegación y reproducción web

Cuando usas el navegador integrado, las páginas y los servidores de contenido reciben las solicitudes normales de navegación. La comprobación de un video puede utilizar las cabeceras y cookies de esa sesión.

## Conexión con TV

El emparejamiento y la reproducción implican comunicación con el dispositivo receptor. En Android TV la aplicación puede abrir un receptor HTTP mientras está en uso. No compartas datos de autorización en reportes públicos.

## Este sitio

GitHub Pages sirve esta documentación. Las páginas de descargas e historial consultan la API pública de GitHub. El sitio no añade analítica, anuncios ni formularios de autenticación.

## Reportes

Para diagnosticar un problema basta con la versión, el modelo de dispositivo y los pasos. Retira cookies, tokens y direcciones de contenido privado antes de adjuntar registros.
